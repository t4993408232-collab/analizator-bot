# Clap Control — MacBook по двум хлопкам

Два хлопка — экран гаснет и Mac блокируется. Ещё два хлопка — экран включается.
Ставится на каждый MacBook отдельно; оба слышат один и тот же хлопок и
срабатывают одновременно.

## Важно знать заранее

- **Это не настоящий сон.** В режиме сна микрофон выключен, и разбудить Mac
  хлопком физически нельзя. Поэтому Mac продолжает тихо работать, а гаснет только
  экран. Со стороны выглядит как сон, но батарея садится быстрее — лучше держать
  на зарядке.
- **Крышка должна быть открыта.** Когда крышка закрыта, MacBook аппаратно
  отключает микрофон.
- Каждый Mac сам определяет, горит ли у него экран. Поэтому два хлопка не
  «перевернут» Mac, который вы разбудили рукой.

## Установка (на каждом MacBook)

1. Скопируйте папку `Mac-Clap` на Mac.
2. Откройте Терминал, перетащите в него `install.sh` и нажмите Enter
   (или выполните `bash ~/Downloads/Mac-Clap/install.sh`).
3. Когда macOS спросит доступ Терминала к микрофону, нажмите **«Разрешить»**.
4. Готово: откроется окно Терминала с логом. Сверните его и не закрывайте.
   После перезагрузки скрипт запустится сам.

## Калибровка (если срабатывает плохо)

```bash
~/.clap-control/venv/bin/python ~/.clap-control/clap.py --test
```

Хлопните пару раз и посмотрите, до какого значения «пик» доходит хлопок и каким
остаётся обычный шум комнаты.

- Хлопки не ловятся → уменьшите порог: `bash install.sh --threshold 0.15`
- Срабатывает от лишних звуков → увеличьте порог: `bash install.sh --threshold 0.4`
- Звук при срабатывании: `bash install.sh --beep`

Интервал между хлопками — от 0,15 до 0,8 секунды (обычное «хлоп-хлоп»).

## Если в логе «микрофон молчит»

Системные настройки → Конфиденциальность и безопасность → Микрофон → включите
**Терминал**. Затем закройте окно Clap Control и запустите заново:
`open ~/.clap-control/ClapControl.command`.

## Удаление

Системные настройки → Основные → Объекты входа → удалите `ClapControl.command`,
закройте окно Терминала со скриптом и удалите папку `~/.clap-control`.
