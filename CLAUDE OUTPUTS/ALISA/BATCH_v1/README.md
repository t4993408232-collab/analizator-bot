## Сценарий (одинаковый каркас, 33 с)

| Время | Что на экране |
|---|---|
| 0–1,5 с | Хук крупно + сразу кадр результата (карточка с готовым ответом) |
| 1,5–6 с | Узнаваемая ситуация: иллюстрация (холодильник, цветок, бумаги…) и две короткие фразы |
| 6–24 с | Демонстрация в телефоне: «Сфоткай…» (видоискатель, вспышка на сильную долю) → «Спроси ИИ» (фото + промпт печатается в чате) → «Ответ за секунды» (точки набора, строки ответа) → «Готово!» (карточка результата) |
| 24–29 с | «И всё это — за минуту» + крупная карточка «Промпт:» (её сохраняют) |
| 29–33 с | «Сохрани, чтобы не потерять» + фраза для репоста; последние 0,45 с плавно переходят в кадр хука, поэтому ролик закольцован |

Ответы ИИ на экране не дают гарантий. У цветка — «похоже на…» и совет показать растение в магазине, у договора — «спорные пункты проверьте у специалиста», у пятна — «проверьте средство на незаметном участке» (в подписи). В ролике про меню фото не нужно: шаг 1 там — «Открой чат с ИИ».

## Стиль

Светлый и тёплый, отдельно от тёмного техно-стиля @igor_ekai. Похоже на ризограф-открытку:
- палитра: кремовая бумага, персик/коралл, шалфейный зелёный, тёплый жёлтый, тёмно-коричневая «краска» контуров;
- предметы нарисованы кодом на Canvas2D: плоская заливка, полутоновая тень и контур со сдвигом краски, как при ризопечати. Чужих картинок, логотипов и аватара нет;
- текст набран Nunito 900 на маркерных подложках со сдвигом, слова выпрыгивают по одному. Подписи на экране не опускаются ниже 75 % высоты кадра (это проверено на контактных листах по красной линии);
- фон — шейдеры из кита, переделанные под светлую гамму: ризограф (две краски растром), солнечный витраж-окно и шёлк.

## Что взято из Code-Video kit (`origin/claude/code-video-kit`, `CLAUDE OUTPUTS/Code-Video/kit`)

Кит запустился, все ролики сделаны на нём. FINAL_v4/pipeline не понадобился.
- `lib/gl.js` — движок: сцена → float RT → переход → пост с mip-bloom, аберрацией, зерном и виньеткой. Скопирован в `pipeline/lib/` с одной правкой: добавлен переключатель `tonemap`, потому что ACES гасил светлую бумагу.
- `lib/glsl.js` (шум, fbm, domain warp, Voronoi, SDF) и `lib/time.js` (`ramp`, `keyed`, `pulseAt`, `beatInfo`, `sectionAt`) — без изменений.
- Сцены `riso.js`, `stained.js`, `silk.js` переписаны в тёплые `scenes/riso_warm.js`, `stained_warm.js`, `silk_warm.js`.
- Переходы кита: fade, burn (витраж → демонстрация), iris (демонстрация → итог).
- Принципы кита: кадр — чистая функция `window.frame(t)`, музыка — это данные (`timing.json`), события ставятся на ближайшую долю (`qb()`), удар на долю (`kick`) и сильная доля (`down`) управляют пульсом текста, бликами и сдвигом красок.
- `render.mjs` — схема кита (headless Chromium + SwiftShader → JPEG pipe → ffmpeg), дописаны режимы `--cover` и контактный лист с линией 75 %.
- `beats.mjs` кита использован для перекрёстной проверки сетки: на треке №2 он нашёл 93,5 BPM при заданных 92.

Трек `kit/assets/track.m4a` и `lyrics.json` не использовались. Файлы кита в эту ветку не закоммичены.

## Музыка

`pipeline/synth.mjs` синтезирует трек без сэмплов: пэд, бас-маримба, мелодия в мажорной пентатонике и мягкий бит (бочка, шейкер, щелчок), плюс простой реверб Шрёдера. У каждого ролика свой темп, тональность, инструмент мелодии и мотив:
1 — 100 BPM, до, щипковая гитара (Karplus-Strong); 2 — 92 BPM, фа, музыкальная шкатулка; 3 — 104 BPM, ре, электропиано;
4 — 96 BPM, соль, маримба; 5 — 88 BPM, ля, электропиано; 6 — 108 BPM, ми, маримба. Громкость приведена loudnorm к −16 LUFS.

## Как пересобрать

```
cd pipeline
npm i puppeteer-core@24.10.0          # или симлинк node_modules
node synth.mjs <id>                   # out/<id>.wav + out/<id>.timing.json
node render.mjs <id> --sheet          # контактный лист
node render.mjs <id>                  # ../<id>.mp4
node render.mjs <id> --cover          # ../<id>_cover.png
node manifest.mjs                     # ../manifest.json
```
Все тексты, палитры и параметры музыки лежат в `pipeline/videos.js`. Шрифты Nunito лежат в `pipeline/fonts` (лицензия OFL).
