# @ailisa.ai.daily — «Алиса ai на каждый день», партия v2 (6 Reels, сложные кейсы)

Учтён отзыв Игоря на v1: кейсы были такие, что любой чат решит с одного вопроса. В v2 каждая задача решается цепочкой из трёх шагов. На входе файл, фото или факты, а работают возможности, которых нет в «просто чате»: анализ файла, проект с инструкцией, генератор музыки и картинок, агент-исследователь, задачи по расписанию.
Стиль, движок, музыка и формат `manifest.json` те же, что в BATCH_v1. Озвучки нет: только текст на экране и своя тёплая музыка в каждом ролике.

## Сценарий (одинаковый каркас, 38 с)

| Время | Что на экране |
|---|---|
| 0–1,5 с | Хук крупно и сразу карточка результата |
| 1,5–5 с | «Обычно: …» — как делают без приёма (долго, нудно). Крупная иллюстрация |
| 5–30 с | Шаг 1 / Шаг 2 / Шаг 3, примерно по 8,3 с: плашка «Шаг N», заголовок, телефон. В шапке телефона указан инструмент шага (файл, проект, генератор музыки, режим «Исследовать», задачи по расписанию). Пользователь присылает файл или фото, промпт печатается, ИИ отвечает результатом: диаграммой, таблицей, песней, картинкой, ссылками, карточкой расписания или уведомлениями |
| 30–33 с | «Результат» — карточка из трёх пунктов |
| 33–35,6 с | «Сохрани схему» — карточка-шпаргалка с тремя шагами и закладкой |
| 35,6–38 с | Фраза для репоста. Последние 0,45 с переходят в кадр хука, поэтому ролик закольцован. Финальной заставки нет |

Темп около 2,5 слова в секунду: промпты на экране сокращены до 4–12 слов, полные версии лежат в подписи. Весь текст выше 75 % высоты кадра: низ телефона на 1430 px, линия проходит на 1440 px. Это проверено на контактных листах.
Честность: числа в роликах (суммы, цены, количество материалов) — это пример, они не обещают результат. В подписях есть оговорки: сверить суммы с выпиской, проверить цены по ссылкам, сверить расход с этикеткой. Бренды упомянуты только текстом, без логотипов и скриншотов интерфейсов: телефон и интерфейс нарисованы кодом.

## Техника

- Движок тот же, что в v1 (взят из Code-Video kit, `lib/gl.js` с переключателем `tonemap`, тёплые сцены riso/stained/silk). Кит в этой партии не понадобился: `pipeline/lib` самодостаточен.
- `app.js` переписан под новый каркас. В нём рендеры результатов шага: `lines | pie | table | image | song | links | sched | notify`. Хук, карточка результата, подписи и обложка взяты из v1.
- `illos.js` содержит новые иллюстрации: выписка с диаграммой, тетрадь с задачей, торт «60» с нотами (вариант-открытка), чемодан с билетом, комната до/после ремонта, календарь с колокольчиком.
- Музыка `synth.mjs` без изменений, у каждого ролика свой трек: 1 — 98 BPM, ре, маримба; 2 — 90 BPM, фа, электропиано; 3 — 104 BPM, до, шкатулка; 4 — 110 BPM, соль, щипковая гитара; 5 — 94 BPM, ля, электропиано; 6 — 100 BPM, ми, маримба. Громкость −16 LUFS (loudnorm).
- Сжатие: H.264 CRF 25 (в v1 было 20), зерно чуть меньше (0,022 вместо 0,03), поэтому файлы весят около 8–15 МБ вместо ~30.

## Как пересобрать

```
cd pipeline
npm i --no-save puppeteer-core@24.10.0
node synth.mjs <id>                   # out/<id>.wav + out/<id>.timing.json
node render.mjs <id> --sheet          # контактный лист
node render.mjs <id>                  # ../<id>.mp4  (--crf N, по умолчанию 25)
node render.mjs <id> --cover          # ../<id>_cover.png
node manifest.mjs                     # ../manifest.json
```

- 0 с: хук читается, под ним карточка результата.
- 1,5 с: смена сцены, подписи «Обычно: …» как раз начинают появляться.
- 19 с (середина): видны «Шаг 2», заголовок шага, инструмент в шапке, промпт и ответ.
- 37,9 с: кадр совпадает с хуком, кольцо замыкается.
Весь текст выше линии 75 %, ничего не обрезано. Найденный брак исправлен до финального рендера: заголовок шага переносился на 3 строки и наезжал на телефон (теперь не больше 2 строк, размер подбирается автоматически); строки схемы заходили под закладку; подпись «обычно» в ролике 6 наезжала на иллюстрацию.
