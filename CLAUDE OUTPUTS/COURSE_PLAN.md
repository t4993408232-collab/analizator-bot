## Курс «Как на самом деле работает ChatGPT» — 20 глубоких роликов (70–120 с)

Шаблон каждого ролика, собранный из данных топа: хук-ломка мифа (≤8 слов) → проверка, которую зритель повторит сам → механизм в 4–6 шагов, на каждом шаге новая картинка → «а теперь самое странное» → приём → «Подпишись — завтра шаг N+1: …».
