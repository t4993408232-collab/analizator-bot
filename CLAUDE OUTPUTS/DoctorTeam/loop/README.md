# DoctorTeam — промо-петля для монитора (исходники)

Петля 14 с, 16:9, без звука. Анимация 0–6 с, QR-кадр 6–14 с, бесшовный повтор. Все кадры считаются кодом. Логотипы рисуются прямо из эталонных SVG, без растровых копий.

## Как сменить QR-код (5 минут)

1. Открыть `config.json` и поменять `url`, `title` или `caption` в блоке `qr`. Там же меняются слова, цифры, слоган и призыв.
2. `node qr.mjs` — пересобирает коды (уровень коррекции H).
3. `node render.mjs` — пересобирает все файлы сдачи в `out/`.
4. `node verify.mjs` — проверяет, что коды читаются и шов петли не виден.

Нужны Node.js 18+, ffmpeg и Chrome или Chromium. Перед первым запуском: `npm install`. Путь к браузеру можно задать через `CHROME=...`. Рендер на видеокарте: `GPU=1 node render.mjs`.

Быстрый просмотр кадров: `node render.mjs --sheet --at 0.3,1.6,3,4.8,8,13.6`. Живой просмотр: `python3 -m http.server`, затем открыть `index.html` и в консоли вызвать `frame(4.8)`.

## Что в папке

| Файл | Что это |
|---|---|
| `config.json` | Тексты, ссылки QR, цвета, шрифт, fps и длительность |
| `loop.js` | Вся анимация: точка → потоки гостей → кольцо → знак D/ в логотипе → рамки → QR → снова точка |
| `logo.js` | Загрузка эталонных SVG и отрисовка их путей, выборка точек внутри знака |
| `qr.mjs` | Генерация QR из `config.json` → `assets/qr.json` |
| `render.mjs` | Рендер и сборка: 4K, FHD, x10 и PNG финального кадра |
| `verify.mjs` | Проверка: декодирование обоих QR на 1/1–1/8 размера и шов петли |
| `assets/` | Эталонные SVG: `doctorteam_primary_white.svg`, `doctorteam_icon_white.svg` |

## Что получается в `out/`

| Файл | Параметры |
|---|---|
| `DoctorTeam_Loop_4K.mp4` | 3840×2160, H.264 High, 25 к/с, ~35 Мбит/с, без звуковой дорожки, ключевой кадр каждую секунду |
| `DoctorTeam_Loop_FHD.mp4` | 1920×1080, H.264, 25 к/с, ~14 Мбит/с |
| `DoctorTeam_Loop_x10.mp4` | Та же 4K-петля 10 раз подряд (2 мин 20 с) |
| `DoctorTeam_QR_Frame_4K.png` | Финальный кадр с QR без потерь, для печати на стенд и роллап |

## Раскадровка, как в ТЗ

| Время | Что на экране |
|---|---|
| 0,0–1,0 | Одна белая точка в центре, пульс «тук-тук» |
| 1,0–2,4 | Точка делится на 720 гостей, они текут пятью потоками, камера отъезжает. Слова по 0,35 с: Конференции · Корпоративы · Форумы · Бренд-зоны |
| 2,4–3,8 | Потоки закручиваются в кольцо с инерцией. В центре кольца по очереди: 500+ событий · 14 лет · Топ-5 АКМР, счётчик докручивается |
| 3,8–5,0 | Кольцо складывается в знак D/: это D из DOCTOR и слэш из /TEAM, на своих местах в логотипе. Затем проявляется остальной логотип, под ним бегущая строка слогана |
| 5,0–6,0 | Логотип уходит вверх, точки разлетаются в две рамки, из рамок проявляются QR |
| 6,0–13,4 | Коды неподвижны. Над ними «Наведите камеру», между ними знак D/, под ними подписи. Точки рамок медленно скользят по периметру, гости дрейфуют по краям кадра |
| 13,4–14,0 | Коды рассыпаются на точки, все точки стягиваются в одну, и петля начинается заново |

Кривые движения везде с инерцией и перелётом. У точек есть глубина резкости, на фоне лёгкое зерно, но не на кодах.
