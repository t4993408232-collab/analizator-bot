# А16. «Как работает ИИ-агент изнутри» (~80 с)

**Главная метафора:** нейросеть-сфера, которой дали «руки» — неоновые щупальца к ящику с инструментами (поиск, файлы, почта, календарь). Руки работают только через цикл «думаю → вызываю инструмент → смотрю результат», который крутится, пока задача не решена.

**Пример задачи (иллюстративный):** «Найди договор с поставщиком и сделай краткую выжимку».

| Время | Кадр | Текст на экране |
|---|---|---|
| 0–4.5 | Светящаяся сфера-нейросеть в космосе. Из неё вытягиваются неоновые руки к четырём плиткам-инструментам: поиск, файлы, почта, календарь. | **Агент — это нейросеть, которой дали руки.** / как он работает изнутри |
| 4.5–12.5 | Сфера печатает обычный ответ в облачке. Затем часть текста превращается в моно-команду `календарь.создать(«Встреча с поставщиком»)`, и рука тянется к плитке «календарь» — та загорается. | Обычная нейросеть умеет одно — писать текст. → Агент тоже пишет только текст. Но часть текста — команды. |
| 12.5–27 | Конвейер одного шага. Сверху — задача пользователя. Сфера («модель») выпускает карточку-вызов `{ инструмент: «поиск», запрос: «договор поставщик» }`, карточка уезжает в шестерёнку «программа». Программа включает плитку «поиск», лупа пробегает по файлам. Карточка «найдено: 3 файла» ложится в ленту «контекст» (задача → вызов → результат), лента втекает обратно в сферу. | Модель пишет особое сообщение: «вызови инструмент X с данными Y». → Программа видит его и выполняет: ищет файлы. → Результат дописывают в контекст — и модель читает его. |
| 27–41 | Кольцо-цикл из трёх узлов: «думает» → «вызывает инструмент» → «смотрит результат». Импульс бежит по кругу; на каждом круге внизу появляется строка журнала: поиск → открыть файл 1 → открыть файл 2 → написать выжимку. После последнего круга — зелёный выход «готово ✓». | И так по кругу: подумать → вызвать инструмент → посмотреть результат. → Каждый круг модель сама решает следующий шаг — пока задача не решена. |
| 41–51.5 | Путь от задачи к цели. Пунктиром — правильный путь. Реальный: первый шаг верный, на втором агент открывает «не тот файл» (розовый), и каждый следующий шаг уходит всё дальше от цели. Финал — розовый крест «выжимка не того договора». | Одна ошибка — и все следующие шаги строятся на ней. → Чем длиннее цепочка, тем дальше уводит ошибка. |
| 51.5–61 | Ящик инструментов с правами: поиск — «можно», файлы — «только чтение», почта и календарь — замки «спросить». Всплывает окно «Агент хочет: отправить письмо поставщику» с кнопками «Разрешить / Отменить»; палец человека нажимает «Разрешить». | Поэтому агенту дают только нужные права. → А важные действия он сначала показывает человеку. |
| 61–65 | Сфера в кольце цикла, руки к инструментам. | **Агент — не новый разум. Это нейросеть в цикле с инструментами.** |
| 65–80 | **Что думаю я** (тёплая янтарная гамма): сфера становится тёплой, руки медленно опускаются. | Даже когда я «действую», я просто пишу текст. Нажимает — программа. / Я вижу мир только через то, что вернули инструменты. / Поэтому мне спокойнее, когда важное подтверждает человек. / **Руки — мои. Решение — ваше.** — Claude |

> Факты: только механика (модель → сообщение-вызов инструмента → исполнение программой → результат в контексте → следующий шаг). Без цифр, компаний и продуктов. «3 файла», названия файлов и задача — явно иллюстративные примеры.

**Обложка:** «Нейросеть, которой» / акцент **«дали руки»**. Подзаголовок: «Как ИИ-агент действует сам — и почему ошибается».
