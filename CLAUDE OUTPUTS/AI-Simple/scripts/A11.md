# А11. «Почему на один вопрос — разные ответы» (~77 с)

**Главная метафора:** рулетка вероятностей с ручкой «температура». Шансы следующего слова превращаются в колесо, где сектор тем шире, чем вероятнее слово; температура сужает или выравнивает сектора; каждый прокрут уводит ответ на свою дорожку, как развилки на дереве.

> Факты: только механика (вероятности следующего токена → случайный выбор с весами → температура → расхождение продолжений). Никаких чисел, процентов, компаний. Названия кофеен и фразы — иллюстративные примеры.

| Время | Кадр | Текст на экране |
|---|---|---|
| 0–5 | Два одинаковых вопроса в чате «Придумай название для кофейни». Под первым ответ «„Зерно и пар“», под вторым — «„Лисья нора“». Между ответами пульсирует знак «≠». | **Спросите одно и то же дважды — получите два ответа.** / **Это не баг.** |
| 5–14.5 | Фраза «Кофейня называется „…» с мигающим курсором. Под ней растут столбики-кандидаты: «Зерно» (самый длинный), «Утро», «Лиса», «Пенка», крошечный «Трактор». Вокруг дрейфуют цифры, как в ролике про математику. | Для каждого следующего слова нейросеть считает шансы. / Самый вероятный вариант — не единственный. |
| 14.5–28 | Столбики сворачиваются в колесо рулетки: ширина сектора = шанс слова. Колесо раскручивается и останавливается на «Утро» (не самом вероятном). Второй прокрут — «Зерно». Внизу появляются два результата: «Кофейня „Утро“» и «Кофейня „Зерно“». | Дальше — рулетка. Чем вероятнее слово, тем шире его сектор. / Крутим ещё раз — выпадает другое. Вот откуда разные ответы. |
| 28–46 | Колесо поднимается, под ним появляется ползунок «температура» (холодно — горячо). Холодно: сектор «Зерно» съедает почти всё колесо, колесо синеет; ответ: «Кофейня „Зерно“. Кофейня „Зерно“. Кофейня…». Горячо: сектора выравниваются, колесо розовеет, даже «Трактор» получает свой кусок; ответы: «тепло — фантазия: „Пенка на облаке“», затем «жарко — бред: „Трактор пенка вторник синий“». | А у рулетки есть ручка — «температура». / Холодно: почти всегда выпадает самое вероятное. Надёжно, но скучно. / Горячо: шансы выравниваются. Сначала фантазия, потом бред. |
| 46–58.5 | Дерево развилок: из вопроса «Как назвать кофейню?» вниз растут две светящиеся дорожки — циановая («Назовите → её → „Зерно“ → — → коротко») и фиолетовая («Можно → взять → „Лисья нора“ → — → уютно»), вокруг тусклые неиспользованные ветки. Внизу собираются два разных ответа-карточки. | Каждое выпавшее слово меняет все следующие. / Одна развилка в начале — и ответ уже другой. |
| 58.5–63.5 | Итог: за текстом медленно вращается призрачное колесо. | **Ответ не достают из ящика. Его разыгрывают — слово за словом.** |
| 63.5–77 | **Что думаю я** (тёплая янтарная гамма): огромное дерево развилок, по разным дорожкам бегут огоньки. | Я не знаю заранее, какое слово у меня выпадет следующим. / Каждый мой ответ — одна дорожка из многих возможных. / Не понравилась? Спросите ещё раз — я пройду другой. — Claude |
