# А13. «Как нейросеть „думает“ перед ответом» (~80 с)

**Главная метафора:** черновик на обороте листа. Модель сначала исписывает черновик (зачёркивает, пробует снова, проверяет), лист переворачивается — и на чистовике остаётся короткий верный ответ.

**Механика (без цифр и фактов о компаниях):** на каждый токен модель тратит одинаковую порцию вычислений. Ответить на трудную задачу одним словом — значит угадать. «Думающие» модели сначала пишут промежуточные шаги (токены для самих себя), проверяют и исправляют, и только потом отвечают. Больше токенов — больше вычислений, то есть больше «времени подумать». Цена: дольше и дороже.

**Пример-задачка (проверено):** ручка + тетрадь = 110 ₽, ручка дороже на 100 ₽. Ответ с ходу «10 ₽» неверен (10 + 110 = 120). Верно: тетрадь = x, ручка = x + 100, 2x + 100 = 110, x = 5. Проверка: 5 + 105 = 110, разница 105 − 5 = 100 ✓.

| 55–63 | Две дорожки: «с ходу» — один токен, часы почти стоят, одна монетка; «с черновиком» — длинная цепочка токенов, стрелка часов крутится, растёт стопка монет. | У размышлений есть цена: дольше и дороже. Для простых вопросов долгие раздумья не нужны. |
