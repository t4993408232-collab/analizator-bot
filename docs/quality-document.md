# Качество модулей

Оценки A / B / C / D по пяти измерениям. Новая сессия смотрит сюда, чтобы
понять, где слабее всего. Модуль на C или D → завести фичу в `feature_list.json`.

- **A** — проходит, понятно, стабильно; **B** — мелочи, ничего не блокирует;
- **C** — тормозит работу агента или даёт нестабильный результат; **D** — сломано.

Обновлять: модуль, который трогал, — в конце сессии; все модули — раз в неделю.
