# Event HR Job Poster v3.0

Автономный агент: ежедневно ищет вакансии event/creative-индустрии на **hh.ru**,
проверяет актуальность, переформатирует под стиль канала и публикует в Telegram.
Реализация спецификации v3.0.

## Что делает

- Ищет вакансии по профилям (event, продюсер, дизайн, motion, marketing, PR, SMM,
  HR, продакшн, подрядчики и т.д.) в странах: Россия, Беларусь, Казахстан, Армения,
  Кыргызстан, Узбекистан (id стран резолвятся из hh `/areas` динамически).
- Проверяет, что вакансия **жива и открывается** (карточка hh, флаг `archived`).
- **Не дублирует** (хранит опубликованные id в `seen_vacancies.json`).
- Зарплата не указана → пишет **«По договорённости»** (ничего не выдумывает).
- Форматирует пост строго по шаблону v3.0 (контакт = настоящая ссылка hh).
- Генерирует иллюстрацию 1024×1024 через OpenAI Images (тёмный фон, 3D-минимализм).
- Расписание: ежедневно в 10:00–20:00 (по одной лучшей вакансии за слот).
- В конце дня шлёт владельцу отчёт (найдено/опубликовано/отклонено + причины).

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен Telegram-бота (обязательно) | — |
| `CHANNEL_ID` | канал для публикации | `@event_hr` |
| `OWNER_CHAT_ID` | чат для отчёта | — |
| `OPENAI_API_KEY` | ключ OpenAI (формат буллетов + картинки) | — |
| `OPENAI_MODEL` | текстовая модель | `gpt-5-mini` |
| `OPENAI_IMAGE_MODEL` | модель картинок | `gpt-image-1` |
| `ENABLE_IMAGES` | генерить иллюстрации (`1`/`0`) | `1` |
| `ENABLE_TELEGRAM_SOURCE` | читать Telegram-каналы (`1`/`0`) | `1` |
| `JOB_SOURCE_CHANNELS` | каналы-источники через запятую (`chan1,chan2`) | пусто |
| `JOB_POSTER_ENABLED` | включить планировщик (`1`/`0`) | `1` |
| `JOB_POSTER_HOURS` | часы публикаций | `10..20` |
| `JOB_POSTER_TZ` | таймзона | `Europe/Moscow` |
| `JOB_POSTER_TOKEN` | секрет для ручного запуска `/job-poster/run` | — |
| `SEEN_FILE` | файл антидубля | `seen_vacancies.json` |

## Ручной запуск (проверка)

```
curl -X POST https://<host>/job-poster/run -H "X-Token: $JOB_POSTER_TOKEN"
```

## Сетевой доступ (egress allowlist)

Агент должен работать там, где открыт доступ к:

- `api.hh.ru` — поиск и карточки вакансий
- `api.telegram.org` — публикация и отчёты
- `api.openai.com` — форматирование и иллюстрации

В песочнице веб-сессии эти хосты могут быть закрыты политикой egress —
тогда вызовы вернут сетевую ошибку. На production-хосте их нужно разрешить.

## Что реализовано и что нет (честно)

- **Реализовано:** hh.ru как источник (единственный с открытым публичным API),
  фильтрация, дедуп, проверка актуальности, форматирование, картинки, расписание, отчёт.
- **Telegram-каналы:** читаются через публичное веб-превью `t.me/s/<канал>`
  (без аккаунта/токена). Список каналов задаётся в `JOB_SOURCE_CHANNELS`.
  Каждый пост разбирается OpenAI строго по фактам; контакт берётся из поста,
  иначе — ссылка на оригинальный пост. Дедуп по permalink. Работает только для
  **публичных** каналов и при открытом доступе к `t.me`.
- **Не реализовано (нужны доступы/аккаунты):** LinkedIn, Behance, vc.ru,
  Habr Career, career-страницы. У них нет открытого API; парсинг требует
  отдельной авторизации/токенов. Точка расширения — добавить функцию-источник,
  отдающую готовые кандидаты в `publish_next` (как `telegram_candidates`).

### Закрытые (приватные) Telegram-каналы

Веб-превью `t.me/s/` работает только для публичных каналов. Если нужны закрытые —
потребуется user-аккаунт через MTProto (telethon/pyrogram) с `api_id`/`api_hash`.
Это отдельная авторизация; по запросу добавлю модуль-источник на telethon.

## Постоянство антидубля

`seen_vacancies.json` лежит в ФС. На хостах с эфемерной файловой системой
(Heroku/Railway free) файл не переживает рестарт — для продакшена замени
хранилище на БД/Redis/volume (точка расширения — `load_seen` / `save_seen`).
